# 核验与异常处理

## 状态与来源冲突

- 以较新的正式公告、立法文书或清楚列明过渡安排的页面为准；无法确认时降为 C 或 D 层，不作为规则更新。
- “已宣布”“开放申请”“注册”“生效”“截止”“审理完成”是不同状态，只使用原文明确支持的表述。
- 州/领地页面与联邦页面分别说明管理范围，不能将州提名条件写成联邦签证资格。

## 热度和敏感议题

- 没有可复核的多来源信号时，不声称某话题“爆了”“热搜”或“所有人都在讨论”。
- 对拒签、庇护、执法、家庭暴力、族裔与犯罪议题，优先解释制度和公开事实；不渲染个案、污名化群体或暴露个人信息。
- 媒体称有变化但官方尚未发布时，保留为 C/D 层并标注“待官方确认”。

## 无法核验

页面失效、登录墙、验证码、无发布日期或无法取得新旧版本时，不把事项写为已变。删除不可靠断言，或转为说明其为何不适合发布。
