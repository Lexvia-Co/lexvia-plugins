# 澳大利亚移民热点选题库

为小红书账号建立每周可用的澳大利亚移民内容选题池。默认覆盖最近一个完整自然周，使用 `Australia/Sydney` 时区。除非用户另有指定，输出 12–20 个候选选题，而不是只挑 3–6 条已生效政策。

## 默认受众与选题优先级

默认优先服务在澳或计划赴澳的中国大陆、香港、台湾、马来西亚、新加坡、越南等中文或亚洲背景用户。这里的地区标签只用于判断内容关联性和信息获取语言，绝不用于推断个人资格、风险或申请结果。

按下列顺序提高选题优先级：

1. 对上述受众有明确、可核验影响的澳洲签证、州担保、国际教育或就业规则更新。
2. 与其常见目的相关的变化：留学与转学、毕业工签、技术移民、雇主担保、打工度假、家属、职业评估和定居就业。
3. 以中国大陆、香港、台湾、马来西亚、新加坡、越南或其他亚洲申请人数据、公开项目、劳动力需求或媒体报道为事实钩子的内容。
4. 其他亚洲地区的相关新闻；只有能解释澳洲签证、留学、跨境就业趋势，或有明显参考价值时纳入。

不要把某国籍写成风险标签，不能从国籍推导拒签率、真实性、违规倾向或个案结果。没有官方按地区分类的数据时，改用“某项面向该地区的公开政策／报道”，而非泛化结论。

## 内容范围

收集与以下主题有关、且对中文受众有实用价值或讨论价值的材料：

- 签证法规、Ministerial Direction、签证费、职业清单、审理优先级、配额、过渡安排；
- 189、190、491、482、186、494、485、500、407、600、417/462 等签证类别，及雇主担保、留学生、入籍；
- 州和领地的提名名额、项目开放状态、职业列表、ROI／邀请规则及居住或工作要求；
- 可信媒体或研究机构报道的移民趋势、处理延误、劳工短缺、院校招生、定居体验、合规执法、法院判例与公共讨论。

将候选材料按证据与内容价值分层，而非只接受“政策已变”的项目：

| 层级 | 可用材料 | 写作要求 |
| --- | --- | --- |
| A：已生效／官方更新 | 法规、官方公告、州项目页、公开数据 | 可写成确定事实，附官方链接与生效状态。 |
| B：正式拟议／待执行 | 已公布的咨询、预算措施、部长表态、已登记但未生效的文书 | 明确写“拟议”“将于某日生效”或“待咨询”，不写成现行规则。 |
| C：行业与社会新闻 | 权威媒体、大学、行业协会、研究报告中的趋势和争议 | 归因到来源，说明不是签证规则。 |
| D：内容灵感 | 多来源出现的高频疑问、公开讨论、政策背景解释角度 | 只作选题线索；不得把线索或社媒帖子作为事实依据。 |

## 取材与核验

- 每周先广泛搜集，再按“与核心受众关联、新近性、公共讨论度、可解释性、可核验性”挑出 12–20 个不重复的方向。通常让至少半数选题直接服务核心受众。
- A 层规则变化必须链接官方原文。B 层优先链接已公开的政府文件、演讲、咨询页或立法文书。具体入口见[来源与发现渠道](references/sources.md)。
- C 层至少链接一篇有编辑规范的原始报道或研究；涉及数字、规则或政策进度时，尽量补充官方或独立来源。
- D 层不得虚构热度或将单一帖子视为趋势。没有足够独立信号时，不放入输出。
- 同一事件只保留一个最有用的角度；可从不同受众切入时，在“可写角度”中列出，不拆成重复事项。

## 发布边界

- 不提供个案资格、成功率、打分预测、递交时机或规避规则的建议；不要要求护照、签证号、ImmiAccount 或完整个人资料。
- 个案故事只能作为经同意公开、已被可靠媒体报道的社会新闻，不外推为普遍规则。
- 规则、签证 subclass、stream、Schedule、Ministerial Direction、lodgement 和 VEVO 等术语保留官方英文；首次出现时可添加简短中文解释。
- 标题可以有吸引力，但不得使用“必批”“全面收紧”“立刻失效”等扩大原意的表述；避免以国籍制造焦虑或对群体作刻板概括。
