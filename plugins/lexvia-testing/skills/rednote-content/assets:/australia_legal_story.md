# 澳大利亚法律内容：故事型通用文案模板

## 使用方法

本模板不限定法律选题。选择一个能说明法律问题的真实案例或情境示例，替换【】内的信息。真实案例注明来源；虚构情境明确标识，不编造真实裁决、办案经历或成功结果。

保留写法：人物困境 → 争议焦点 → 关键事实与证据 → 结果或可能路径 → 可借鉴的做法。

## 传播设计与热度说明

人物处境与冲突形成阅读动力；逐步揭示关键事实帮助读者理解法律判断；结尾提供可借鉴的做法。预期侧重阅读完成、共鸣与信任，不代表已经在澳大利亚受众中取得实测热度。
