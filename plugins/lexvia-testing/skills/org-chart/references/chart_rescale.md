RESCALECHART
Purpose
---
Rescale an editable chart in Microsoft Word document to fit within the Word page margins and without hindering any information. 

Required Information
---
- a Microsoft Word file with an editable chart

Workflow
---
1. Inspect the Word document to confirm the org chart is native SmartArt or editable Word shapes, rather than a screenshot.

2. Resize proportionally from a corner handle until it fits within the Word page margins. Use Landscape orientation or narrower margins if the hierarchy is wide. 

3. Resize text boxes vertically(or horizontally if the chart orientation is Landscape) and adjust font sizes so that all text in text boxes are visible. 

4. Adjust connectors so that there is no overlap between connectors and text boxes. 

5. Confirm all labels remain legible, no boxes overlap, and the chart stays on one page. Adjust Word page size, margins, or font sizes only as needed.

6. Save as a new .docx in the chosen destination, without overwriting an existing file.

7. Check that the Word document is valid and can be opened in Microsoft Word without errors. If not inpsect the XML file and fix any error.
