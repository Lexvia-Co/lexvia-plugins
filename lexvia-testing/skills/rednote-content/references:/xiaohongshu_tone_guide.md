# 小红书文体风格指南 | Xiaohongshu Tone Guide

适用对象：撰写中文小红书图文或口播稿的作者、编辑与写作助手。  
适用范围：不限定选题；另设澳大利亚法律科普的表达要求，可配合清单型、故事型、误区纠正型模板使用。

## 1. Voice & Tone — 核心声音

**像一个做过功课、愿意把事情讲清楚的人，和有同样疑问的读者交流。**

读者应能很快知道：这篇和自己有什么关系、能学到什么、下一步可以做什么。

| 维度 | 默认表达 | 写作边界 |
| --- | --- | --- |
| 亲近 | 自然称呼“你”，承认读者的困惑 | 不默认读者的性别、年龄、身份或情绪 |
| 清晰 | 先给核心信息，再解释原因与条件 | 不为制造悬念拖延答案 |
| 温和 | 解释选择，帮助读者理解 | 不训话，不羞辱，不替读者下情绪结论 |
| 有活力 | 有节奏的短句、适量提问 | 不靠连续感叹号和热词堆叠维持语气 |
| 不绝对 | 多用表达概率的词汇语句 | 不使用绝对语气的词汇比如绝对，确定，一定 |

默认语气可以随情境调整：生活经验分享稍轻松；办事指引更直接；纠纷、损失或家庭问题更克制。幽默可以针对情境，不针对当事人的脆弱处境。

## 3. Basic Writing Policy — 基础写作原则

1. **一篇回答一个核心问题。**动笔前写下“读者看完应该明白什么”。删去与该目标无关的支线。
2. **先交付信息。**开头两三句话给出问题、结论或本篇用途，不用行业发展史铺垫。
3. **从读者的具体处境进入。**用“收到一封看不懂的通知”这类可理解的场景，代替“面对复杂多变的现实环境”。
4. **口语化，但保留准确含义。**优先用“先看、核对、保留、说明、申请”等动作词；必要术语第一次出现时解释。
5. **一段只讲一个意思。**句子有多个条件时拆开写；条件与结论放在一起。
6. **把好处写具体。**说明“帮助你核对材料是否齐全”，不要只写“满满干货”“认知升级”。
7. **数字必须有来处。**清单有三项可以写“三项”；调查比例、金额、期限和成功率必须有依据。
8. **第一人称必须真实。**“我经历过”“我的客户”“我实测了”只能用于确有其事的内容。资料整理可写“这篇整理了……”。
9. **同理心通过帮助体现。**可以说“这两个概念确实容易混淆”，少用“我太懂你的崩溃了”等代入式表演。
10. **让读者保有选择。**解释条件、步骤和取舍，不用恐惧迫使读者关注、咨询或购买。
11. **保留原创与来源。**改写他人观点要注明出处；案例、数据和重要结论应能追溯。商业利益关系如存在，应清楚披露。

## 4. Structure & Rhythm — 标题、开头与正文节奏

### 标题

优先组合“场景／人群／地点”与“具体问题／明确用途”。标题中的承诺必须在正文兑现。

- 问题型：`在【地点】遇到【问题】，先看什么？`
- 清单型：`准备【事项】前，核对这【数字】件事`
- 区分型：`【概念一】和【概念二】，差在哪里？`
- 故事型：`【人物或情境】遇到【争议】，关键在这一点`

标题保持一眼可读，尽量只承载一个主问题。确需说明适用地区时，不要为了缩短标题删掉地区。具体发布长度和展示效果以编辑器预览为准。

### 开头

三种开头任选其一，不必每篇都用同一个句式：

- **场景引入：**“收到【材料】，却不知道该先核对哪一项？这篇把顺序整理出来。”
- **回答疑问：**“【条件】就意味着【结果】吗？先说结论：【含必要限定的回答】。”
- **事实引入：**“在【已核实案例】中，双方争议的是【问题】。决定判断的细节是【事实】。”

避免“今天给大家带来一篇超级实用的干货”，直接进入内容。

### 正文

- 每个小节先写结论或动作，再解释原因。
- 初稿以三至五个要点为起点；如果要点更多，按问题分组。
- 一段通常一至三句，段间留空行。不要为了短段落把完整意思切得支离破碎。
- 给出一两个必要例子，帮助读者判断是否理解，不为凑篇幅重复结论。
- 字数以讲清单一问题为准。内容过密时拆成图卡或系列，不删掉改变结论的条件。

### 结尾

用“一句总结＋一个可选动作”收束。动作应来自内容本身：

- “可以先把【材料】按日期排好，再逐项核对。”
- “这份清单适合在【具体时机】拿出来检查。”
- “下一篇你更想看【问题一】，还是【问题二】？”

不要求每篇都提问，也不同时要求点赞、收藏、关注、转发和私信。

## 5. Phrases to Avoid — 应避免的话术与替代表达

以下是编辑取舍，不代表这些词一出现就违反平台规则。真实引文或讨论话术本身时可以出现。

| 类型 | 避免或慎用 | 推荐处理 |
| --- | --- | --- |
| 假数据 | “99%的人都不知道”“十个人九个中招” | “这个问题需要区分两种情况”；有真实调查时注明样本、日期和来源 |
| 结果保证 | “包赢”“稳拿赔偿”“百分百成功” | “是否成立，需要核对【条件与证据】” |
| 虚构权威 | “内部消息”“官方不会告诉你”“业内不传秘招” | 直接标明信息来自哪个公开机构或文件 |
| 恐惧催促 | “再不看就晚了”“不收藏血亏” | 如有真实期限，说明起算点和适用范围；没有期限就删去紧迫感 |
| 情绪表演 | “救命！！”“震惊了”“看完直接破防” | 直接描述发生了什么、问题在哪里 |
| 亲昵称呼 | 每段都喊“宝子们”“家人们”“姐妹们” | 默认用“你”，确有明确受众与账号习惯时偶尔使用称呼 |
| 空洞赞美 | “封神”“天花板”“绝绝子”“王炸干货” | 写具体用途、内容或可验证的特点 |
| 训话羞辱 | “这都不懂”“别傻了”“你就是太好欺负” | “先确认【事实】，再判断下一步” |
| 群体标签 | “房东都……”“律师只会……”“男人／女人就是……” | 聚焦这件事中各方的行为、主张和证据 |
| 假经历 | “昨天又帮客户拿回……”但没有真实材料 | “情境示例：……”或“根据【公开案例】……” |
| 万能操作 | “照抄就行”“一句话搞定”“直接套用” | “下面是表达示例，请按实际事实和适用范围修改” |
| 平台玄学 | “这样写必上热门”“这个词一定限流” | “这是一种可测试的写法”，没有证据不作算法归因 |
| 套话铺垫 | “随着社会不断发展”“在当今时代背景下” | 从一个具体场景或问题开头 |
| 抽象包装 | “赋能”“抓手”“底层逻辑”“闭环”“认知跃迁” | 改成实际动作及其作用，如“核对记录”“列出下一步” |
| 空洞转折 | 反复用“值得注意的是”“毋庸置疑”“综上所述” | 删掉连接套话，直接写信息 |
| 强迫互动 | “评论扣1才发资料”“先关注再告诉你” | 本篇交付已承诺的信息，互动只用于补充问题 |
| 符号绕词 | 用拼音、谐音或符号替代正常专业词 | 使用准确名称；需要修改时调整实质内容 |
| 绝对语气 | 绝对，通常，肯定，一定 | 使用表达可能性高低的词汇比如可能，应该，有可能 |

## 6. Preferred Language — 可以自然使用的表达

这些是句式参考，不需要逐篇逐条插入。

- **引入：**“如果你正准备……”“先把这个问题拆开看。”“这篇主要回答……”
- **解释：**“这里说的……是指……”“它会影响的是……”“可以先看这两个条件。”
- **区分：**“两者分别对应……”“满足这个条件后，还需要核对……”
- **提醒：**“有一个细节容易漏掉：……”“这一点需要结合……判断。”
- **行动：**“先保存……”“对照……检查。”“在邮件里写清楚……”
- **边界：**“这份指引适用于……”“如果发生在其他州，需要另查当地规则。”

少用“不是……而是……”作为每段的固定结构。能直接说明的，就直接说明。

## 7. Formatting & Emoji — 排版、表情与话题

- 正文用小标题、编号和留白建立节奏，避免整段都加粗或每行都加图标。
- 表情符号可不使用；需要时，初稿控制在零至三个有明确作用的符号，例如用“📌”标记小结。这是风格默认值。
- 对伤害、重大损失、家庭冲突等内容不使用庆祝或幸灾乐祸式表情。
- 中文句子用中文标点。问号用于真实问题，感叹号偶尔使用，不连续堆叠。
- 话题选择与正文直接相关的主题、人群或地点；不强行加入无关热词，不把标签写成第二遍正文。
- 关键词自然出现在标题与说明中，不机械重复“澳洲、澳大利亚、澳洲法律”等近义词。
- Markdown 用于整理稿件；发布前检查实际显示效果，不假定小红书会原样渲染加粗、表格和链接。

## 8. Australian Legal Content — 澳大利亚法律科普的语气要求

本节规定表达方式，不提供具体法律结论，也不限定法律选题。

1. **地区写清楚。**涉及特定州或领地的规则时，就近写明；不要把地方程序写成“全澳都适用”。
2. **使用当地概念。**必要时采用“中文解释＋官方英文名称或缩写”，之后使用一致简称。不要直接套用中国的机关、程序或法律称谓。
3. **结论和条件同句或相邻。**不能在标题保证结果，再把关键例外藏在文末。
4. **期限说明起算点。**同时写明何种程序适用；尚未核实的期限不能当成确定结论发布。
5. **金额说明口径。**涉及金额时注明澳元，并按需要说明税前、税后、估算或个案数额。
6. **案例区分主张与认定。**“一方要求支付”不能改写成“法院判赔”；申请、裁定、生效和执行也要分别表述。
7. **语气帮助读者判断。**避免“拿捏对方”“教你反杀”“钻空子”等对抗式包装。
8. **个案互动不过度收集信息。**可以询问读者想了解哪个一般问题，不邀请其在评论区公开身份、完整文书或其他敏感资料。
9. **来源靠近结论。**发布稿记录官方机构、页面名称、链接及核对日期。将一般信息与个案分析分开表达。
10. **身份如实说明。**不凭文风暗示作者具有未经证实的澳大利亚律师资格或办案经历。

结尾如有必要，可使用一句与内容相符的范围说明，例如：“本文介绍【管辖范围】的一般规则，具体适用取决于【关键因素】。”范围说明不能代替正文准确性。

## 9. Adaptation to Three Formats — 三种写法的语气变化

| 写法 | 语气重点 | 保留的结构 | 避免 |
| --- | --- | --- | --- |
| 清单型 | 清楚、直接、有帮助 | 具体问题 → 核对事项 → 下一步 | 清单只列名词，不解释用途；声称适用所有情况 |
| 故事型 | 有代入感、事实清楚、情绪克制 | 处境 → 争议 → 关键事实 → 结果或路径 → 提醒 | 编造第一人称、刻意塑造反派、虚构胜诉结局 |
| 误区纠正型 | 回答明确、尊重提问者 | 疑问 → 结论 → 条件 → 例子 → 做法 | 羞辱不懂法律的人；把有条件的结论写成绝对判断 |

## 10. Before & After — 原创改写示例

以下仅演示文风，不构成具体法律判断。

### 示例一：删掉空洞铺垫

**改前：**随着社会不断发展，法律意识日益增强，如何有效维护自身合法权益已成为社会各界关注的重要课题。

**改后：**收到一份看不懂的通知？先找出三项信息：谁发出的、要求你做什么、有没有注明回复期限。

**变化：**用具体场景和可执行动作替代背景套话。

### 示例二：保留故事，去掉戏剧化包装

**改前：**震惊！澳洲打工人终于逆袭，一招让对方彻底认输！

**改后：**情境示例：小林发现双方对同一件事的说法不同，于是把邮件和记录按时间排好。分歧具体出在哪一步，这才逐渐清楚。

**变化：**明确是虚构情境，交代动作与作用，不编造真实胜负。

### 示例三：纠正误解，保留必要条件

**改前：**别傻了！这都不知道，难怪你一直吃亏！

**改后：**满足【条件一】，就能得到【结果】吗？还需要核对【条件二】。这两个条件分别解决不同的问题。

**变化：**把指责改成问题，把情绪改成解释；发布时填入经过核实的内容。

## 11. Editorial Review — 出稿前快速检查

- [ ] 前两三句话已经说明问题、结论或用途。
- [ ] 标题与正文一致，没有未经支持的数字或结果承诺。
- [ ] 每段有明确作用，删去重复套话后仍然通顺。
- [ ] 第一人称、案例、引文和数据有依据，虚构情境已标识。
- [ ] 必要术语已经解释，重要条件没有被删掉。
- [ ] 澳大利亚相关内容注明适用地区，法律与程序没有跨法域混用。
- [ ] 语气尊重读者，没有群体标签、羞辱或强迫互动。
- [ ] 正文给出了与选题相符的实际帮助。
- [ ] 重要信息有来源和核对日期，未把营销建议当作平台规则。
- [ ] 已检查手机阅读效果，表情、强调和话题没有压过内容。

## 12. Reusable Writing Brief — 可复用写作指令

> 请面向【目标读者】，用中文撰写一篇小红书【图文／口播】稿，主题为【主题】，适用范围为【澳大利亚联邦／州或领地／其他范围】。
>
> 采用【清单型／故事型／误区纠正型】结构。语气自然、清楚、温和，开头直接说明具体问题或用途；用短段落、具体动作和必要例子解释。
>
