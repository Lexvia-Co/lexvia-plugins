SMARTART DISPLAY FORMAT
-----------------------
- Use the format defined below consistently in each SmartArt box in the organisation chart:

   [Name]\n[Title]\n[Status]

- The details in each SmartArt box are short enough to remain legible.

- Do not include title box in the Chart. 

- If the document the chart is in has a header or footer, chart colour should match the colour the header or footer.
Otherwise, use the following palette for the chart:
  text box background color: olive grey
  box outlines and connectors: light grey
  text: black 

- Text font must be Times New Roman

- When one text box is connected with multiple text boxes, use right-angled connectors not straight-lined connectors between the parent text box and child boxes. 

- There must be no overlap between each text box and connector in the chart.
